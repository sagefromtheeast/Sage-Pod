Free podcast player for Android

Podcasts that stay on your phone.

Sage Pod is a free, open-source podcast player for Android. Subscribe to any show, download episodes for the train, and keep your listening history where only you can see it.

Read the code on GitHub Coming to Google Play

Free software under the GNU GPL. Every release is public on GitHub.

Follow anything with a feed.

Search millions of podcasts, browse the charts for your country, or paste a feed address from any show's website. Private and paid feeds with a password work too, and an OPML file brings your subscriptions over from the app you use now.

Questions

Is Sage Pod really free?

Yes. There are no ads, no subscription and no paid tier. It's free software, so the code is free too.

Do I need an account?

No. Open the app and subscribe.

Can I bring my podcasts from another app?

Export an OPML file from your current app and import it in Settings › Import/Export. You can export one from Sage Pod the same way whenever you want to leave.

Does it work offline?

Downloaded episodes play anywhere. Searching and refreshing feeds need a connection.

Where is my data stored?

On your phone: subscriptions, history, statistics and settings. Automatic backups go to a folder you choose.

Does it work with private or paid feeds?

Yes, if the feed gives you an address, with or without a username and password.

Is there an iPhone version?

Sage Pod is built for both, but only the Android app is published for now.

How is it related to AntennaPod?

AntennaPod's feature set is the benchmark Sage Pod is working through. Sage Pod is a separate app written from scratch and shares no code with it.

How do I report a bug or ask for a feature?

Open an issue on GitHub. Security problems go through the private report described in SECURITY.md.
